## 🚀 Projets principaux

### 📚 ScolarAI

Application mobile et API dédiées à la numérisation de bulletins scolaires malgaches.

Le projet permet notamment de :

- capturer une image avec la caméra ;
- importer une image depuis la galerie ;
- détecter les zones importantes d’un bulletin ;
- effectuer une reconnaissance optique des caractères ;
- enregistrer et corriger les résultats ;
- exporter les données au format PDF ou Excel.

**Stack :** Flutter, Dart, Python, FastAPI, YOLO OBB, TFLite, TrOCR, Firebase Firestore, SQLite et Sqflite.

- [Application mobile ScolarAI](https://github.com/rakotna/M1-projet)
- [API backend ScolarAI](https://github.com/rakotna/ScolarAi_Back)
